Motion Detect 1.0.2
Fonazza-Stent

The program works with a camera to detect a change in the picture,
such as an object or a person moving, and capture frames in a folder, so
it can be useful as a motion detection program, i.e. for security
purposes.
- Launch the program and a picture window will appear showing the
scene seen by the camera connected to the computer
- If if doesn’t exist, a “capture” folder will be created, to store
the moving objects captured by the program
- When a person or an object moves in front of the webcam, the
corresponding images will be captured and stored in the “capture”
folder
- The “log.txt” file created by the program contains timestamps of
every time the program starts
- Press “q” to close the picture window
